# ImageShrink

**Free offline batch image resizer and compressor for Windows.**

Resize and compress multiple images locally — no uploads, no account, no subscription.

ImageShrink is made for quick batch jobs: add your images, choose the resize/compression settings, process the whole batch, and download the results.

## Features

- Batch process multiple images
- Resize by maximum width and height
- Percentage-based resizing
- JPEG quality control
- Target file-size option
- Download individual processed images
- Download the full batch as a ZIP
- Works locally on your computer
- No image uploads
- No account required

## Free Version

This repository provides the free version of ImageShrink.

The free version is intended for trying the workflow and handling smaller batch jobs.

A full version with expanded batch capabilities is also available on itch.io.

## Privacy

ImageShrink processes images locally.

Your images are not uploaded to a server.
